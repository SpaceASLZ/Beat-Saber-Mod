# QuestLyrics

QuestLyrics is a Beat Saber Quest mod project designed to display timed song lyrics in a floating panel while playing.

## Target Device
- Meta Quest 3S
- Beat Saber 1.40.8
- Standalone Quest installation

## Planned Features
- Identify the currently playing custom song.
- Retrieve timed lyrics from LRCLIB when available.
- Display the current lyric and the upcoming lyric in-game.
- Synchronize lyrics with song playback.
- Handle songs without available timed lyrics gracefully.

## Development Status

This project is in early development.

The following components still need to be implemented and tested:
- Native Beat Saber mod integration
- Song metadata detection
- Online lyrics retrieval
- Floating in-game lyrics display
- Beat Saber 1.40.8 compatibility
- Native Android build and QMOD packaging

**No installable QMOD is available yet.**
